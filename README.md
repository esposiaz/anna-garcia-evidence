# Anna Garcia — Interactive Evidence Email

Fictional classroom forensic-science exhibit.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `anna-garcia-evidence`.
2. Upload **all files in this folder** to the repository root (not the ZIP itself).
3. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Once deployed, open the URL shown in the Pages settings and test all eight images and the video.

The eight photos remain in chronological order. The original email text, timestamp, and attachment layout are preserved. The video is a reconstruction from still images, not original continuous surveillance footage.

**Privacy:** Standard GitHub Pages sites are publicly accessible. Use school-approved restricted hosting if access must be limited to your class.
